## ASCII Art Rain 🌧️

A simple terminal animation that displays falling rain using ASCII characters!

### Usage

```bash
python3 rain.py
```

Press `Ctrl+C` to stop the animation.

### Features

- Random rain drops with varying speeds
- Different rain drop characters (|, :, !, ., ')
- Adapts to your terminal size
- Smooth animation
